## 💼 Experience

### Data Analyst — Airtel *(Jul 2021 – Jul 2024)*

- Pulled prepaid churn and recharge frequency data from **Snowflake** using optimized joins and subqueries to support quarterly subscriber retention analysis across multiple regional circles
- Modeled telecom billing and plan-tier relationships in a **dimensional schema**, standardizing reporting across regional business units and improving cross-team data consistency
- Created **Power BI** reports with **DAX** measures tracking daily active users, data consumption, and revenue per circle, giving product teams reliable self-serve visibility into KPIs
- Ran **A/B tests** on promotional plan offers and summarized results using descriptive statistics, delivering pricing recommendations that guided go-to-market decisions for the product team
- Documented data definitions and KPI logic in a shared data dictionary, reducing recurring analyst clarification requests by an estimated **20–30% per sprint cycle**

- Queried subscriber transaction and usage data using advanced **SQL** with CTEs and window functions to surface KPIs, delivering consistent insights for weekly stakeholder reporting

- Built **3 Tableau dashboards** tracking ARPU, churn rate, and plan adoption metrics, enabling commercial and operations teams to monitor performance trends in a single consolidated view
- Designed **Excel-based KPI frameworks** to benchmark regional sales performance and flag month-over-month deviations, supporting faster leadership review cycles
- Applied **descriptive statistics** to segment subscriber cohorts by usage behavior, providing targeted retention planning recommendations that informed campaign strategy
